Name the package, service or subsystem under review here, and the question the

## Boundaries

- Both analysis tasks are read-only. They must not edit, commit or stage
  anything, and a verification command checks that the working tree is clean.
- Each analysis writes one file and keeps it short enough to be read in full.
- Neither analysis knows what the other found. The join task is where the two
  meet.
