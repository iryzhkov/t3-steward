# Internal child-review cancellation contract

Source: candidate 8984d2e08551423f9bff87e029ccd655130eede1, parent afb3dad3cf532b927b35cb6cb0a12724828fc424, plus this bounded local change. The trusted Store.ReconcileReviewChildCancellation API accepts only original FrozenAuthority and CheckpointAuthority. No migration, public CLI/wire schema, coordinator hook, live provider call, or policy re-resolution is added.

The SQLite writer serializes binding validation, parent disposition, child execution/assignment validation, token revocation, offered release, attempt CAS, audit and round CAS. Existing immutable materialization, graph definitions, all-attempt and artifact union ownership validators remain in use. Authority index scope, round revision, parent history/latest, run/task/project identities, assignment scope/epochs/states/dispatch indexes/lease indexes and runtime records must agree. Corrupt, missing, ambiguous or foreign records refuse with rollback; a validator error is never interpreted as an ended parent.

Before the immutable deadline, a latest live original parent with the same claimed assignment epoch, thread and executor route is no-action. Coherent parent run termination, original attempt termination, a newer parent attempt, assignment unknown/released/completed, or a greater replacement epoch requests cancellation. A missing original assignment, lower epoch, changed same-epoch thread/route, offered original parent, or invalid current execution refuses. The immutable deadline wins at equality and cannot be extended by the mutable round or replay.

Every nonterminal child attempt, including older stranded executions and legitimate new retries, is cancelled/stopped. Dispatch tokens in runtime assignment records are cleared before the attempt CAS, following existing RevokeTaskAuthority's authorization convention: the unique dispatch_token lookup index is retained, not treated as authority. Offered never-started ready/queued/blocked assignments with no dispatch evidence release only via matching offered-state/epoch/attempt CAS. Claimed/unknown ownership and epoch remain intact. Completed/released historical assignments remain valid when existing reconciliation clears the attempt's assignment reference.

Cancellation audit identity is checkpoint plus attempt. Terminal attempts, existing artifacts, immutable input/prompt receipt bytes and prior round results are preserved. Pending members get failed (or timed-out at the original deadline) only when their latest execution was newly cancelled; a terminal latest execution is collector-owned even if its older execution needs stopping. An already accepted round cannot strand unfinished child work. Reopen/repeat is mutation-free for already cancelled attempts; newly appearing legitimate retry IDs are still cancelled. No new intent marker or completion grant is created.

The result distinguishes no-action, stop-requested and durable quiescent custody. WorkerStopPending is conservative durable nonquiescence, not transport acknowledgement. RunExecutionsQuiescent includes all historical attempts and assignments; cancellation alone cannot free claimed/unknown ownership or settle a sink. Existing PlanWorkerCommands plans stable Stop, or Collect on completed observations. Command persistence alone does not acknowledge a stop. Existing acknowledged worker state transitions release/complete ownership, preserve cancelled progress, and reject stale pre-cancellation completion projections. Existing ProjectRunSink and SettleNodeWaits own sink/wait settlement; this operation does not mutate the parent or manufacture wake/context grants.

Disposable tests exercise those planner, acknowledgement, reconciliation, collector and wait boundaries. Worker acknowledgements in tests are simulated; no live stop is asserted. The production caller and final admission fence remain future integration work: reconciliation must precede dispatch planning, retry admission must prevent resurrection, and stale accepted dispatch commands without current worker observation must not reactivate terminal work. This unit demonstrates stale completion and observed-completion fences, not every future runtime dispatch ordering. Independent Sol and Astra reviews follow; this document does not accept the change or claim full M16, CI, publication or deployment.
